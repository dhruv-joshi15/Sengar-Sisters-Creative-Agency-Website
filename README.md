# Sengar Sisters

Next.js creative-studio prototype. Run `npm install`, then `npm run dev`. Validate with `npm run typecheck`, `npm run build`, and `TEST_BASE_URL=http://localhost:3007 npm run test:e2e` against a running production server.

Editable content: `data/siteData.ts` (founders, services, chapters, contact); `data/instagram.ts` (four public channels, Crispygirl selected by default); `data/work.ts` (seven supplied real posts and dated public metrics). Dark mode is the default with Light and System options and persisted preference. All eight chapters share measured native-scroll progress and navigation highlighting.

Home is a studio-first typographic poster with two layered contour-sketch creatives in scroll-responsive 3D perspective, bright lime accents and faded SENGAR SISTERS typography. About presents Apoorva first as Founder and Aditi second as Co-founder, using both supplied original portraits with their complete composition and colours. The short photographic studio interlude is an explicitly labelled AI-created visualisation, not a portrait of the founders. It uses bounded native parallax rather than drawn figures, a giant camera, flashing, or an extended pinned scroll.

Work contains all seven supplied Instagram originals in compact translucent glass cards over a local leafy SVG backdrop, with full source compositions, scroll-in arrangement, keyboard focus effects and responsive filtering. Public plays are labelled views rather than unique reach; unavailable view counts are not invented. Bhansali’s starting 8K and July 2026 anniversary are studio-provided; the public profile showed 21.3K on 14 September 2026. Two physically hinged phones open on scroll: a vertical flip-screen study illustrates Virdi’s 0 → 4.4M plays and a horizontal fold-screen study illustrates Bhansali’s 8,000 → 21,300 followers inside a linked public-profile preview. Both have a bounded blur-to-clear reveal, replay/open-close controls and static reduced-motion alternatives. Counters illustrate reported public snapshots, not live analytics. FindYourVibe’s small like badge is omitted. Sample clients, results, testimonials and the unfinished showreel have been removed. Source details: `docs/work-sources.md`; generated asset and exact prompt: `docs/studio-visualisation.md`.

Phone and WhatsApp icon links use +918839689424. WhatsApp opens with a prefilled inquiry; phone opens the dialler without initiating a call. Paper-plane transitions precede standard contact navigation, with reduced-motion alternatives. An email address has not been supplied, so no dummy email destination is shown. The inquiry form is a validated local preview and does not send or store messages.

Responsive local Next/Image assets retain source colour and composition. Aditi’s actual 9:16 portrait is uncropped. No backend, heavy graphics package or scroll hijacking. Mobile retains all work, channels and interactions while adapting the layout.

The inquiry form sends through the configured mail provider; locally, without credentials, it composes an addressed draft and the visitor must press Send in their email app. See `docs/inquiry-delivery.md` for the two Vercel environment variables.
